      • 1. Choose language – leave it on Auto detect or pick the language you are using.
      • 2. Enter free text – describe what the business does in 2–4 sentences.

      About this project

      Industrial Code Studio is a semantic search layer on top of curated industrial activity codes. It uses a fine‑tuned multilingual transformer model to understand nuanced business descriptions and surface the closest matching codes.

      Typical use‑cases include onboarding new companies into registry systems, validating activity descriptions for compliance, and exploring similar activities for market intelligence.

      How it works

      • The description is optionally translated to English for embedding.
      • A sentence‑transformer model embeds both the query and every industrial code description.
      • Cosine similarity is used to rank codes; the top match is returned.
      • A lightweight rationale explains the decision and shows nearby codes in the embedding space.

      Data and privacy

      Inputs are primarily short business descriptions. For production deployments you can wire this app to a secure SQL database and implement retention policies that match your regulatory environment. Avoid entering personal or sensitive data in this demo.
